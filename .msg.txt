v0.2.3: bilingual console, clarify zero-dependency, browser-free CLI

Publishes the bilingual web console work (Chinese / English switch, language
remembered in localStorage, dynamic views re-rendered on switch) and folds in
this round's fixes.

On the "zero dependency" claim: it was only ever about the install footprint, and
the README never said so, which made it read as "needs nothing at all" while the
web console plainly needs a browser. Both READMEs now separate the two facts -
CLI, MCP and SDK are pure command line and pure code; only `serve` renders in a
browser, and skipping it costs no functionality.

New 命令行.bat gives an interactive prompt so the engine is usable without ever
opening a browser. Verified: add, search and stats all work, and search output
shows the graph working ("关系第 1 名（用户 --住在--> 上海）").

启动控制台.bat now locates itself with %~dp0 instead of a hardcoded absolute
path, and probes several node locations.

assets/membrane.ico: seven-size icon drawn for this project.

Both .bat files are GBK + CRLF.

Version bumped to 0.2.3 in package.json, doctor, MCP serverInfo and the README
badges.

Tests: 212 passing. Consistency check reports all documents match.
